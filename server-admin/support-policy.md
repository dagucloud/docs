# Support Policy

## Supported versions

Fixes go into the latest stable release series and the `main` branch. Older releases do not receive fixes, including security fixes, and there is no long-term support (LTS) release.

To get a fix, upgrade to the latest stable release. See [Upgrades](/server-admin/upgrades).

| Version | Receives fixes |
| --- | --- |
| Latest stable release series | Yes |
| `main` | Yes |
| Older releases | No |

If you report a problem on an older release, you may be asked to confirm it on the latest stable release first.

## Where to get help

| Plan | Channel | Response |
| --- | --- | --- |
| Community, Team, and Pro | [GitHub Issues](https://github.com/dagucloud/dagu/issues) and Discord | Best effort |
| Enterprise | As set out in the agreement | First-response targets on the [SLA page](https://dagu.sh/sla) |

Team and Pro licenses unlock product features and do not include support.

## Security reports

Do not open a public issue for a suspected vulnerability. Follow the [security policy](https://github.com/dagucloud/dagu/blob/main/SECURITY.md). New reports are acknowledged within 5 business days.
