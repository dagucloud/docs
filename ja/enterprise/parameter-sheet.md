# パラメータシート

Dagu の主要な設定項目と既定値をまとめた Excel ファイルです。設計書の下書きとして使えます。

[パラメータシートをダウンロード (xlsx)](/ja/enterprise/dagu-parameter-sheet.xlsx){target="_blank"}

## シートの構成

| シート | 内容 |
| --- | --- |
| 使い方 | 記入の方法と注意事項 |
| パラメータ | 設定キー、環境変数、既定値、説明、推奨値。「設定値」の列に記入します。 |
| ホスト一覧 | ホスト名、役割、OS、データディレクトリ、マウントオプションなど |

## 記入の方法

1. 「パラメータ」シートの「設定値」の列に、環境での値を記入します。既定のままの場合は空欄で構いません。
2. 「ホスト一覧」シートに、Dagu を動かすホストを記入します。
3. 記入した値を `config.yaml` または環境変数として設定します。環境変数には `DAGU_` の接頭辞が付きます。
4. 設定後、`dagu config --values` で、各項目の値と設定元を確認できます。

すべての設定項目は [Configuration Reference](/server-admin/reference) (英語) にあります。
