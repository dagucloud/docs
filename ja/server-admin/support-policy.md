# サポートポリシー {#support-policy}

## サポート対象のバージョン {#supported-versions}

修正は、最新の安定版リリース系列と `main` ブランチに適用されます。それより古いリリースには、セキュリティ修正を含め、修正は提供されません。長期サポート(LTS)リリースはありません。

修正を適用するには、最新の安定版リリースにアップグレードしてください。[アップグレード](/ja/server-admin/upgrades)を参照してください。

| バージョン | 修正の提供 |
| --- | --- |
| 最新の安定版リリース系列 | あり |
| `main` | あり |
| それより古いリリース | なし |

古いリリースの問題を報告された場合は、まず最新の安定版リリースで問題を確認していただくようお願いすることがあります。

## サポートの窓口 {#where-to-get-help}

| プラン | 窓口 | 対応 |
| --- | --- | --- |
| Community、Team、Pro | [GitHub Issues](https://github.com/dagucloud/dagu/issues) と Discord | ベストエフォート |
| Enterprise | 契約に定めるとおり | [SLA ページ](https://dagu.sh/sla)に記載の初回応答目標 |

Team および Pro ライセンスは製品の機能を有効にするものであり、サポートは含まれません。

## セキュリティの報告 {#security-reports}

脆弱性が疑われる場合は、公開の Issue を作成しないでください。[セキュリティポリシー](https://github.com/dagucloud/dagu/blob/main/SECURITY.md)に従ってください。新しい報告には、5 営業日以内に受領の連絡をします。
